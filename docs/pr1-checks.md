# Проверка ПР 1

Дата: 15 ноября 2026 года.

| Проверка | Результат |
| --- | --- |
| Файлы HTML | 16 страниц, во всех один `h1`, язык `ru`, UTF-8 и `viewport` |
| Ссылки и изображения | Все локальные пути и якоря существуют; у изображений заполнен `alt` |
| Поля формы | Подписи `label` связаны с существующими полями |
| Наполнение | На главной 6 карточек, в каталоге 12 |
| Стили | Общий `style.css`, атрибутов `style` в разметке нет |
| Изображения | Проверены 11 фотографий WebP, одна фотография JPEG и логотип SVG; товарные SVG заменены |
| HTTP | Все 16 HTML, 13 изображений сайта и CSS возвращают статус 200 на локальном сервере |
| Главная на широком экране | Визуально проверены шапка, вводный блок и сетка карточек |
| Ширина 360 px | Открыты все 16 страниц; ширина документа не превышает ширину окна |
| Мобильный вид | Дополнительно просмотрены контакты и корзина; таблица прокручивается внутри блока |
| Клавиатура | Меню «Товары» открывается клавишей Enter, все 12 ссылок появляются в дереве доступности |
| Пример корзины | 4 × 490 + 100 × 28 + 3 × 410 = 5 990 ₽ |
| Nu HTML Checker | Все 16 страниц прошли проверку без сообщений; в каталоге исправлен неверный закрывающий тег option |
| Базовый аудит доступности | На пяти типах страниц проверены alt, подписи полей, язык, main, h1, отсутствие пустых ссылок и стиль фокуса |
| Контраст | Основной текст 13,47:1; вспомогательный 5,95:1; зелёные ссылки на белом фоне 7,85:1 |
| Клавиша Tab | Проверен переход к ссылке «К содержимому» и логотипу |

Каталог использует отложенную загрузку (`loading="lazy"`): изображения ниже экрана могут загружаться только при приближении к ним. Наличие файлов и их выдача по HTTP проверены отдельно.

Проверка проведена во встроенном браузере приложения. Перед защитой стоит повторить проход клавишей Tab и включение мобильного режима в том браузере, который будет использоваться на занятии. Полная инструкция находится в `pr1-notes.md`.

В `report-assets/html-validation.json` сохранены фактические ответы валидатора, в `report-assets/accessibility.json` — результаты базовой проверки DOM. Это ограниченный аудит, а не полная проверка WCAG. `report-assets/checks.html` представляет результаты в удобном виде для снимка в отчёт. Скриншоты показывают пять обязательных типов страниц; товар представлен карточкой цемента.
