# Проверка реализации

Дата: 9 ноября 2026 года. Окружение: Linux, Python 3.12, Node.js 24, Chromium через agent-browser. Проверялось работающее приложение FastAPI, а не только HTML-файлы.

## Автоматические проверки

- `python -m pytest -q`: **11 passed**. Известное предупреждение совместимости Starlette/AnyIO о deprecated alias не влияет на результат; не скрывается настройками тестов.
- `npm run check:html`: все 7 документов прошли html-validate с рекомендуемыми правилами; стиль DOCTYPE и пустых тегов согласован с Prettier.
- `npm run check:js`: синтаксис JavaScript корректен.
- `npm run format:check`: форматирование frontend соответствует Prettier.
- `npm audit`: 0 известных уязвимостей в зависимостях инструментов проверки на дату выполнения.
- Axe-core 4.10.3: на всех 7 страницах при 360 px нет автоматически выявленных нарушений WCAG 2 A/AA и WCAG 2.1 AA после исправления контраста номеров на главной. Проверка контраста части содержимого возвращает `incomplete` и требует ручного просмотра; это **не сертификат полного соответствия доступности**.

## Что ещё требуется для сдачи

- Результат сборки и чистого запуска Docker проверяется отдельной задачей GitHub Actions на текущем commit. Сам факт наличия Dockerfile не подтверждает успешную сборку.
- Постоянный публичный хостинг и HTTPS ещё не настроены. Preview используется только для разработки.
- Для итогового отчёта нужны все иллюстрации из методички: снимки всех страниц на двух размерах, Network с внешним запросом, состояния ошибок, схема БД, API-документация, доказательство хеширования на тестовых данных без секретов, сборка контейнера и постоянный HTTPS-адрес.
- Не выполнены ручной аудит со скринридером и полная проверка клавиатурой. Автоматический axe не заменяет эти проверки.
- Требуются сведения для титульного листа и оформление итогового DOCX/PDF по вузовскому шаблону. План отчёта в репозитории не считается готовым отчётом.
