# Замена иллюстраций фотографиями

Фотографии можно сохранить в формате WebP. Положить их нужно в `site/images/` с такими именами:

| Файл | Товар |
| --- | --- |
| cement.webp | Цемент М500, мешок 50 кг |
| plaster.webp | Гипсовая штукатурка, мешок 30 кг |
| glue.webp | Плиточный клей, мешок 25 кг |
| putty.webp | Финишная шпатлёвка, мешок 20 кг |
| brick.webp | Керамический полнотелый кирпич |
| block.webp | Газобетонный блок |
| drywall.webp | Гипсокартон |
| plywood.webp | Фанера ФК |
| board.webp | Обрезная доска |
| insulation.webp | Минеральная вата |
| paint.webp | Краска для стен, ведро 10 л |
| primer.webp | Грунтовка, канистра 10 л |

Удобный размер для этого проекта — 720 × 500 пикселей: это вдвое больше текущих иллюстраций с теми же пропорциями. Лучше использовать одинаковые пропорции, спокойный фон и фотографии, где упаковка или материал видны целиком. Файлы желательно укладывать примерно в 50–200 КБ без заметной потери качества. Это ориентиры, а не ограничения формата.

Простое переименование SVG в WebP формат не меняет: нужна настоящая фотография, сохранённая или экспортированная в WebP.

После добавления фотографий нужно:

1. В HTML заменить пути `images/имя.svg` на `images/имя.webp`. Товар может встречаться на главной, в каталоге и на своей странице; менять нужно все вхождения.
2. Если фотографии имеют пропорции 720 × 500, существующие атрибуты `width="360" height="250"` можно оставить: соотношение сторон совпадает.
3. Обновить `alt`, убрав слова «условная иллюстрация товара», и описать то, что действительно на фотографии.
4. Сверить названия, вес упаковки и характеристики с изображениями. Если на фото мешок 25 кг, нельзя оставлять в карточке 50 кг.
5. Записать ссылки на источники фотографий и условия их использования в этот файл.
6. Проверить сайт и обновить снимки и описание изображений в отчёте.

Логотип `logo.svg` можно оставить векторным: он не является фотографией товара.

Пока фотографии не добавлены, сайт продолжает использовать SVG. Одного добавления `.webp` рядом с ними недостаточно: браузер загружает файл, явно указанный в `src`.
