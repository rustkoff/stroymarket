# ПР 2: пояснения для защиты

Автор: Шустов Фёдор Александрович, ЗН251. Вариант 14, «СтройЗапас».

## Демонстрация

1. Запустить HTTP-сервер по README. В каталоге ввести `knauf`, выбрать «Изоляция»: останется один товар. Очистить поиск, выбрать листовые материалы и сортировку. Показать пустой результат и «Сбросить».
2. По ссылке над каталогом перейти к калькулятору. Vetonit Стронг: 9 м², запас 10 % → 4 листа. Knauf: 2,7 м² без запаса → 3 листа. Доска: 0,09 м³ без запаса → 2 штуки. Показать ошибки для 0 и отрицательного запаса.
3. В контактах нажать «Проверить сообщение» с пустыми полями, затем заполнить имя, email и сообщение. Успех означает только проверку, отправки и сохранения нет.
4. В каталоге открыть блок «Цена в другой валюте». Выбрать товар и EUR. В DevTools → Network найти `daily_json.js`: внешний адрес, HTTP 200 и JSON с Date, Valute, Nominal, Value. Дата курса может быть раньше текущей.
5. В Network выбрать Offline и нажать «Повторить загрузку курсов». Конвертация исчезает, появляется сообщение об ошибке; фильтр и калькулятор работают. Вернуть No throttling и повторить загрузку.
6. Включить ширину 360 px и пройти форму клавишами Tab, Shift+Tab, Enter. После ошибки фокус переходит на первое неверное поле.

## Как работает код

HTML описывает страницу и исходные 12 карточек. CSS отвечает за вид, JavaScript — за события и изменение DOM. Скрипты подключены через `defer`: выполняются после разбора HTML, в порядке подключения. Библиотек и сборки нет.

- `catalog.js`: `input` реагирует на поиск, `change` — на списки. `trim`, нижний регистр и замена ё на е упрощают поиск. Условия названия и категории объединены через `&&`. `hidden` скрывает неподходящие карточки. Копия массива сортируется по числовому `data-price`, `append` переставляет существующие карточки. Исходный массив сохраняет порядок для сброса. `setTimeout` после reset ждёт восстановления значений формы.
- `feedback.js`: `preventDefault()` отменяет штатную отправку. Все поля проверяются, ошибки показываются через `textContent` рядом с ними. `aria-describedby` связывает подсказку с полем, `aria-invalid` сообщает об ошибке, `role="status"` объявляет результат. Пользовательский текст не вставляется как HTML. Обработчики не используют сеть или localStorage.
- `calculator.js`: объект `materials` хранит размеры девяти конкретных товаров в метрах и единицы продажи. `readDecimal` принимает точку и запятую, запрещает отрицательные значения, экспоненты, пустую строку и слишком длинную дробь. `calculateQuantity` делит потребность с запасом на покрытие одной единицы. `Math.ceil` округляет вверх. Поправка в несколько `Number.EPSILON` возле целого убирает машинную погрешность, не округляя заметный недостаток материала вниз. При правке полей старый результат очищается.
- `currency.js`: `fetch` получает JSON асинхронно, `await` ждёт ответ, не блокируя страницу. HTTP-ошибка не вызывает catch автоматически, поэтому проверяется `response.ok`. Затем проверяются дата и положительные числа USD/EUR. `catch` обрабатывает сеть, HTTP и JSON, `finally` снимает признак загрузки. `AbortController` ограничивает ожидание 10 секундами. Повторная загрузка доступна через 1,1 секунды после запроса. Ответ не заменяется локальными данными.

Клиентская проверка нужна для удобства. Когда в ПР 3 появится сервер, он должен будет независимо проверять входные данные.

## Формулы и ограничения

`Количество = ceil(потребность × (1 + запас / 100) / покрытие единицы)`.

| Материал | Единица потребности | Покрытие единицы продажи |
| --- | --- | --- |
| Vetonit Стронг, Мультикомфорт | м² | 2,5 × 1,2 = 3 м²/лист |
| Knauf влагостойкий | м² | 1,5 × 0,6 = 0,9 м²/лист |
| Vetonit ветрозащитный | м² | 3 × 1,2 = 3,6 м²/лист |
| Фанера ФК | м² | 1,525 × 1,525 = 2,325625 м²/лист |
| ТеплоKnauf 100 мм | м² | 9 м²/упаковку, заявлено производителем |
| Кирпич ЛСР М150 | м³ | 0,25 × 0,12 × 0,065 = 0,00195 м³/шт. |
| Газобетон ЛСР D400 | м³ | 0,15 × 0,25 × 0,625 = 0,0234375 м³/шт. |
| Доска | м³ | 0,05 × 0,15 × 6 = 0,045 м³/шт. |

Потребность: больше 0 и до 10 000 включительно, до 6 дробных знаков. Запас: 0–50 %, до 2 дробных знаков. Листы считаются в один слой. Для кладки вводится объём изделий без растворных швов. Раскрой и схема кладки не моделируются; запас выбирает пользователь. Цемент и клей не включены: геометрических размеров недостаточно для определения расхода. Источники характеристик сохранены в `product-sources.md`.

Конвертация: `цена в рублях × Nominal / Value`. Например, Value — это рубли за Nominal единиц валюты. Основная цена не меняется. Сортировка сравнивает цены за единицу продажи, поэтому не показывает стоимость одинаковой площади разных материалов.

## Внешний источник

Выбран предложенный методичкой сторонний сервис [API для курсов ЦБ РФ](https://www.cbr-xml-daily.ru/). Это не собственный сервер и не официальный домен Банка России. [JSON endpoint](https://www.cbr-xml-daily.ru/daily_json.js) доступен без ключа. Документация и условия проверены 15.11.2026: не более 1 запроса/с, 30/мин, 10 000/сутки на IP; обязательная обратная ссылка размещена на сайте. Не следует многократно обновлять страницу для демонстрации.

Проверка из Edge с origin `http://localhost:8000` дала HTTP 200 и читаемый ответ типа `cors`. При загрузке сайта выполняется один запрос. Изменение валюты или товара использует уже полученный объект без новых запросов. `cache: 'no-store'` позволяет проверить настоящий отказ сети при повторной загрузке. CORS — разрешение браузеру читать ответ другого origin; `no-cors` здесь не используется, потому что его непрозрачный ответ нельзя прочитать как JSON.
