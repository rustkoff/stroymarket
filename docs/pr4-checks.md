# Фактические проверки ПР 4 и сервера

Дата: 15.11.2026. Адрес: https://rustkoff.ru/.

## Исходное состояние (до изменений)

Репозиторий `/root/stroymarket`, чистый main, origin `https://github.com/rustkoff/stroymarket.git`, HEAD `c1e1e9b`. Вторая копия не создавалась. Debian 13, около 2 ГиБ RAM, около 19 ГиБ свободно, swap нет. Работали Nginx, Xray/3x-ui, AdGuard Home и SSH; Docker отсутствовал.

Nginx stream слушал :443 и направлял SNI домена в Xray/Reality `127.0.0.1:1443`. Обычный HTTPS попадал в fallback Nginx `127.0.0.1:8443`, отдававший `/var/www/html`. Заглушка HTTPS отвечала 200. Порт 80 не слушался. Certbot timer был включён, способ продления — standalone. Сертификат rustkoff.ru/www.rustkoff.ru действовал с 23.09.2026 по 22.12.2026.

AdGuard слушал DNS :53 и HTTP-панель `127.0.0.1:3001`; его TLS/DoH был отключён. Публичный `/dns-query` и внутренний HTTP-запрос DoH возвращали 404, панель — 302. Клиентское VPN/DoH-подключение не проверялось. Конфигурации клиентов и их идентификаторы в доказательства не включены.

## Что изменено

- Установлены Docker/Compose, инструменты Python, Chromium/Playwright, LibreOffice, Poppler и шрифты для проверок и отчёта. Обновление всей ОС, reboot, prune, удаление чужих контейнеров/томов не выполнялись.
- Создан `/etc/docker/daemon.json`: без bridge, iptables/ip6tables, forwarding и masquerading; ротация логов.
- Создан контейнер `stroymarket-shop-1`: непривилегированный UID 10001, сеть host, bind только 127.0.0.1:18080; постоянные данные `/var/lib/stroymarket`.
- В существующем nginx.conf добавлен HTTP include и заменён только обработчик заглушки; фрагменты `/etc/nginx/stroymarket-location.conf`, `/etc/nginx/stroymarket-http.conf`.
- Порт 80: ACME webroot `/var/www/letsencrypt`, остальные запросы 301 на HTTPS. Firewall уже разрешал этот порт; правила не менялись.
- Certbot успешно переведён на webroot командой reconfigure (проверка через staging CA). Добавлен `/etc/letsencrypt/renewal-hooks/deploy/stroymarket-nginx-reload`: валидатор и reload. Производственный сертификат сохранён.

До изменения действующей конфигурации сделаны копии nginx.conf и renewal/rustkoff.ru.conf, снимки сервисов, портов и firewall в `/root/backups/stroymarket-20261115`, каталог 700, файлы 600. Там же `rollback.sh` с правами 700. Кандидат прошёл `nginx -t` до установки; применён reload.

Путь TLS проверялся через домен с самого VDS; это не независимая внешняя пользовательская сеть. Внешний веб-инструмент не смог открыть адрес. Успешный ACME challenge подтверждает доступность проверки сертификата извне, но не заменяет браузерную проверку всех сценариев из другой сети.

Остаётся владельцу открыть магазин через мобильную/другую сеть и проверить подключение настоящим VPN-клиентом. Восстановление реальной рабочей БД из копии и полный откат на действующем сервере не выполнялись: подготовлены команды и проверены копия/валидатор, чтобы не создавать лишний перерыв в работе.
