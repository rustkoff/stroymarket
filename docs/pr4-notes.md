# ПР 4: пояснения для защиты

Адрес: https://rustkoff.ru/. Для показа нужна своя учебная запись; публичного общего пароля нет.

1. **Образ и контейнер:** Dockerfile описывает образ с Python, закреплёнными зависимостями и исходниками. Контейнер — запущенный процесс из образа. Рабочая БД не входит в образ.
2. **Постоянные данные:** `/var/lib/stroymarket` на VDS примонтирован как `/data`; SQLite переживает удаление и пересоздание контейнера. Сессии тоже находятся в SQLite. Показать `docker-compose ps`, `/health`, затем результаты restart/recreate в `report-assets/pr4/deployment-checks.json`.
3. **Права:** UID 10001 вместо root, без capabilities, read-only rootfs, временный `/tmp`, ограничения ресурсов. Docker сокет и настройки других служб не смонтированы.
4. **Сеть:** на данном VDS Docker работает без моста/iptables/forwarding. Compose использует сеть хоста, Uvicorn слушает только `127.0.0.1:18080`. Host network не даёт сетевой изоляции — это осознанный компромисс для действующего VDS.
5. **Reverse proxy:** внешний Nginx stream читает SNI, существующий Xray/Reality обрабатывает VPN; обычный браузер попадает на его fallback Nginx :8443. Тот передаёт магазин на :18080. Изменён только обработчик заглушки. Не нужно разбирать конфигурации или показывать данные VPN-клиентов на защите.
6. **HTTPS:** прежний сертификат Let's Encrypt остаётся на внутреннем Nginx. Certbot теперь проверяет владение доменом через webroot на порту 80; все остальные HTTP-запросы перенаправляются на HTTPS. Таймер продлевает сертификат, hook выполняет `nginx -t` и reload. Тестовый CA использовался только для проверки продления.
7. **Запуск после загрузки:** включён docker.service, у контейнера restart unless-stopped. Перезагрузка сервера не выполнялась; проверены настройки автозапуска и реальные restart/recreate контейнера.
8. **Логи и health:** stdout/stderr Docker, ограничение 10 МБ × 3; healthcheck проверяет HTTP/SQLite. Пароли и тела форм приложение не логирует. Healthcheck не перезапускает зависший процесс автоматически.
9. **Бэкап:** `scripts/backup.py` использует SQLite backup API, учитывающий WAL. Копии вне Git, права 600. Перед обновлением сохраняются база и предыдущий образ; полный откат прокси подготовлен отдельно.
10. **Границы проверки:** TLS и пользовательские сценарии проверены через домен с самого VDS; внешняя ACME-проверка прошла. Отдельный внешний веб-инструмент домен не открыл, поэтому доступ из другой пользовательской сети остаётся непроверенным. Процессы VPN/AdGuard работают, но полноценное VPN/DoH-подключение не проверено. DoH уже возвращал 404 до публикации.

Для демонстрации: главная → каталог → калькулятор → регистрация → товар → корзина → заказ → личный кабинет → `/docs`. Затем показать Dockerfile, Compose, постоянный каталог, README и результаты проверок. Не показывать `.env`, cookie, конфигурации VPN или содержимое реальных аккаунтов.
